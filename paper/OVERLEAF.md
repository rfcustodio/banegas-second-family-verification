# Overleaf compilation instructions

This directory contains the **draft IEEE Access manuscript**, with the original
mathematical sections preserved and the measured area--depth comparison added.

## Recommended import

1. Download the **banegas-overleaf-complete.zip** artifact from the successful
   `Build revised paper and Overleaf ZIP` GitHub Actions workflow.
2. In Overleaf choose **New Project > Upload Project** and select that ZIP.
3. Set **main.tex** as the main document.
4. Use **pdfLaTeX** as the compiler and **BibTeX** for references.
5. Compile. The four new PDF figures and the original three figures are included.

The packaged `compiled-preview.pdf` is a reference copy of the CI-compiled paper,
not the source file.

## Experimental provenance

The additional figures are generated by
`plot_measured_comparison.py` and `plot_measured_pareto.py` from
the immutable GitHub Actions run **43631263668**, artifact **area-depth-1100**
(commit `e80e57fb4f9fbe2784052b6690879d232a7852e6`).
The script checks the 405 shared degrees and their area/depth ordering.

## Scientific qualification

The optimized BCP Algorithm 3 construction for the first family at `b=2c`
has not been independently reproduced as a measured verified SLP. The
measured comparison excludes it. The manuscript is a complete compile-ready
**review draft**, not a claim that this unresolved scientific point is closed.
